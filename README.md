# 📦 Inventory Management CLI (Pure Java)

> **"A base de um grande desenvolvedor começa no domínio da lógica pura."** > Este projeto é uma engine de gerenciamento de inventário minimalista, desenvolvida sem frameworks para consolidar conceitos avançados de Java SE e Orientação a Objetos.

---

## 🚀 Funcionalidades

O sistema simula o backend de um controle de estoque via terminal (CLI), permitindo:

* ✨ **CRUD Completo:** Criação, leitura, edição e exclusão de produtos.
* 🧠 **Gestão de Estado Inteligente:** Manipulação de listas dinâmicas (`ArrayList`) em tempo de execução.
* 💎 **Clean Code:** Aplicação rigorosa de encapsulamento e padrões de nomenclatura.
* 🛠️ **Tratamento de Dados:** Entrada de dados robusta utilizando a API `Scanner`.

---

## 💻 Tecnologias Utilizadas

Para este projeto, foquei no uso de ferramentas nativas do ecossistema Java para garantir performance e compreensão total do código:

## 🏗️ Conceitos Aplicados (O que eu aprendi)

Neste projeto, demonstrei competência técnica em:
1.  **POO (Programação Orientada a Objetos):** Criação de classes, atributos privados e métodos acessores.
2.  **Ciclo de Vida de Objetos:** Instanciação, manipulação e destruição de dados em memória.
3.  **Lógica de Controle:** Estruturas de repetição (`while`) e condicionais (`switch/case`) para menus interativos.
